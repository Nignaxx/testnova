# NovaDeck - launcher PS Vita

Lance tes jeux Vita, PSP (via Adrenaline) et toutes les vieilles consoles (via RetroArch).
Commandes : L/R console, croix gauche/droite jeu, X lancer, Triangle scraper, Start quitter.

## Obtenir le fichier .vpk sans rien installer
1. Cree un compte sur github.com et un depot vide (bouton "New repository").
2. Envoie-y tout le contenu de ce dossier (Add file > Upload files), en gardant les dossiers.
3. Onglet "Actions" : la compilation demarre toute seule. Quand c'est vert, ouvre l'execution
   et telecharge l'artefact "NovaDeck-vpk" : il contient NovaDeck.vpk.
4. Copie le .vpk sur la Vita et installe-le avec VitaShell.

## Utilisation
- Au premier lancement, ux0:data/NovaDeck/roms/<CONSOLE> est cree. Mets tes ROM dedans.
- Triangle = scraping des jaquettes (Wi-Fi requis). Les noms de ROM doivent suivre les noms
  No-Intro, par ex. "Pokemon - Emerald Version (USA, Europe).gba". Rond pour annuler.
- Pre-requis : RetroArch (RETROVITA) installe avec ses cores, et Adrenaline pour la PSP.
